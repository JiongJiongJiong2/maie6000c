# Procedure supplied to the skill-query agent

Infer likely meme/template canonical identity only when supported by the description.
Use canonical English aliases for international templates and Chinese character/movie
aliases for Chinese memes. For editability prioritize `blank template` or `无字 原图`;
for animation prioritize `GIF` or `动图`. Omit unnecessary narrative. If identity is
uncertain use visual attributes; never invent a known meme title. Produce one query.

This is a versioned experimental instruction fixture, not an installed runtime skill.
