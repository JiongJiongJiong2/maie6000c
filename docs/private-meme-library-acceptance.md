- GitHub 的 `dev` 为 `1e8feb0`，续搜分支为 `5f202ae`。实现以 `5f202ae` 为基线，合入时依赖该提交及其收藏历史。

- 确认历史收藏属于同一所有者。API 与 worker 使用同一个专用 PostgreSQL 库、同一媒体卷及对应的参考库和模型缓存。此前如用共享部署，先在隔离副本核对所有权和已有媒体。
