## 2026-11-12 门槛加固

再次配置检查仍为三项 key 缺失。上一轮新增安全配置工具属于实际进展；本轮继续完成最终证据校验，未调用付费服务、未重复提交失败任务。

- `score` 将实际真人标签冻结为输出目录中的 `labels.csv`，记录其 SHA 和 manifest SHA；`finalize` 对这些文件及每条下载重新解码、校验、重算指标，不能只信 `status=passed` 或手改汇总数字。
- 标签错配其他 attempt、缺失标签快照、修改后的 CSV、文件格式/MIME/帧数与字节不符均拒绝。质量通过还必须有完整标签、有限数值和达到门槛的实际指标。
- `passed` 的成员复现声明必须提供 `run_evidence`，指向其独立运行的 `evidence.json`；必须是空文字、有实际结果、数据库对账通过，且输入 SHA、job、revision、数量与声明一致。再次校验媒体文件。单纯勾选所有布尔项不能满足 A8；真人身份与独立性仍由实际成员签署，执行 agent 不代填。
- 浏览器通过记录必须与实际分页 ID 集合、下载文件一致；动画证据需解码后有实际像素变化，不能用不同 PNG 元数据/编码制造“变化”。筛选、移动布局、暂停、离开视口暂停及按需加载也成为 A6 必须项。
- 实际浏览器采样等待动画图片解码完成，减少加载空白到首帧被误当动画的风险。
- 审阅页补真实来源链接；只允许合法 http(s) 来源，外部字符串转义，图片仍只从本轮本地验证文件加载。
