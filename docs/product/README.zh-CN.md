# MemeRetrieve 产品说明

[English](README.md) · 简体中文 · [文档首页](../README.zh-CN.md)

手里只有一张截图时，MemeRetrieve 可以帮你找回原始动态 GIF。上传裁好的画面，播放候选动画，核对动作和字幕。找到目标后可把原件收藏进私人库，下次换一帧截图也能再找。下载时拿到的是原始动图文件。

## 截图会送到哪里

| 选项 | 截图如何处理 | 用户能做什么 |
| --- | --- | --- |
| **Local only**（仅本地检索） | 浏览器把截图上传到 MemeRetrieve 服务器。服务器在参考库和当前账号已建索引的收藏里查找。 | 查看并播放至多三个候选，或者看到没有候选的结果。若使用托管部署，本地模式下托管服务器同样会收到截图。 |
| **Online search / Continue online**（联网搜索 / 继续联网搜索） | 部署者启用并配置联网功能后，所选识图供应商会收到缩小的截图或代表帧。DeepSeek 负责规划查询和搜索网页。 | 在 **Search activity** 查看进度。结果可能同时包含静图和动图，播放确认后可点 **Confirm and save** 收藏。 |
| **邀请制公测演练** | 网页运行在运营者自己的电脑上。新用户注册需要邀请码；演练配置关闭外部搜索和 AI 标注。 | 测试者可以导入 GIF、用截图检索、重新登录并下载已保存的原件。运营者可配置私密反馈表单。 |

常规安装初始选中联网搜索；主动选择 **Local only** 后，该次检索只在服务器上运行。**My GIF Library** 支持批量导入，原件按账号保存。等索引就绪后，服务重启仍能本地找回。启动方式和网页操作见[使用与部署指南](../guides/README.zh-CN.md)。

## 整理和复用原件

私人库支持编辑标题和标签、按文字搜索、查看疑似重复的 GIF，以及导出和还原备份。在启用了外部 AI 标注的部署上，用户可选择具体 GIF，确认后才发送抽样帧供识别。设备支持分享 GIF 文件时，**Share GIF** 会把原件交给系统分享菜单；最终如何发送或导入取决于接收应用。[私人库验收](../private-meme-library-p0-p1.md) · [网页与分享回执](../../submissions/week13/browser-release-verification.json)

## 已验证的效果

邀请制演练使用一份有授权的 44 帧地球 GIF。取第 13 帧查询，目标排在第一。重启 API 与 worker、用全新浏览器重新登录后，第 29 帧截图仍首位命中同一资产。两次下载均与参照原件的 1,001,718 字节逐字节相同。另一次联网测试中，操作者提供画面描述和来源网站后找回了该 GIF，记录中也保留了此前六次未成功的尝试。[公测演练回执](../../submissions/week13/public-beta-rehearsal.json) · [联网检索回执](../evidence/gif-acquisition/hkgai-web-offline-20261128.json)

在固定的 12 个参考 GIF 上，多帧检索有 12/12 个目标进入前三，仅索引首帧时为 11/12。查询截图均取自对应 GIF。独立聊天截图经过裁剪、加字或遮挡后的原件命中率仍待测量。[逐项评测结果](../../submissions/week13/local-corpus-evaluation.json)

## 谁可能愿意付费

首轮建议面向经常需要从自有图库找回特定版本 GIF 的创作者与内容运营者，验证他们是否愿意为私人库托管和协助导入持续付费。报价、转化和续费目标均为后续试点假设。[商业模式与试点设计](../business-model.md)

账号隔离、原件持久化、图像帧向量和 NPZ 回退等实现见[技术文档](../technical/README.zh-CN.md)。
