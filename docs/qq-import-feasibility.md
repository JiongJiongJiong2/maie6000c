# QQ 直接导入可行性核查（2026-11-15）

用户目标：不安装辅助 App，从项目网页直接把任意检索所得 GIF 添加成 QQ 可复用表情，
允许格式转换，但发送后须保留动画。发送图片后手动收藏不算一键导入。

## 已找到的官方资料

腾讯云历史《API 文档》游戏 SDK 功能包含 `TencentOAuth.addQQEmoji(emojiID)`。
资料更新时间为 2018-01-15，示例是 iOS Objective-C 原生调用，参数为已有表情包 ID，
文档要求联系游戏 SDK 开发方了解该 ID，并描述鉴权失败等返回值。
这不是接受任意 GIF URL/字节的网页接口；其当前可用性未验证。

- [腾讯云 API 文档，游戏 SDK 功能，第 61 页](https://mc.qcloudimg.com/static/qc_doc/7bd19fe9268d975f64e2169a511074d4/14715.pdf)
- [腾讯云 iOS API 使用说明，第 42 页](https://mc.qcloudimg.com/static/qc_doc/bec61286d85e1b8c1e096635fd912985/11880.pdf)

检索还遇到腾讯云 IM/TUIKit 自定义表情资料，属于接入该聊天 SDK 的自建应用，
不能据此推断可写入个人 QQ 账号的收藏表情。旧电脑 QQ 的 ActiveX、EIF/EIP 导入说明
也不能直接套到 iPhone Safari。第三方机器人/修改客户端路线不属于本次不装辅助程序
的网页实现范围，没有下载或运行这些工具。

QQ 移动网页 SDK 的 `open.mobile.qq.com` 说明与脚本地址在本次网页工具访问中不可达。
不能声称已完整检查当前所有 QQ 网页 API，不能因搜索未找到就断言绝对不存在。

## 当前结论和交付状态

尚未找到有官方依据、符合上述要求的网页调用方案。没有构造未知 scheme、冒用其他
应用 ID 或把只打开 QQ/分享 GIF 的按钮标为导入成功。
没有新增 QQ 实验页，没有修改正式页面、公共接口或业务字段。本调查记录随 `codex/chat-import-experiments` 分支交接。
QQ 一键导入与 QQ GIF 分享均未做真机验证。本轮只有可行性调研，不是代码功能完成。

继续实现需要新的具体依据，例如接受自定义 GIF 的官方网页导入方法、满足权限条件的
QQ 内置网页能力，或可由项目生成并被当前 iOS QQ 识别的表情包文件格式及导入入口。
在找到这样的入口前，不要求用户重复无针对性的手机测试。
