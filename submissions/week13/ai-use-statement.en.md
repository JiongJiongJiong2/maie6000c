# AI use and verification

English · [简体中文](ai-use-statement.md)

At runtime MemeRetrieve can use HKUST or HKGAI to describe what is visible in an uploaded screenshot. DeepSeek plans queries and searches the web. Local CLIP computes image and text representations. Model output supplies clues for retrieval. The team checks the actual file, decoded frame count, source and SHA-256 to verify the original. The user decides whether to save an item in the web app.

For this delivery, Codex assisted with branch inspection, code integration, Windows path and timezone fixes, test development, browser operation, database design documentation and delivery materials. Verification included actual provider calls, comparisons of browser downloads, migration and state checks in isolated PostgreSQL, and single-frame versus multi-frame retrieval on the licensed reference collection. Runs that failed to find the original online are included in the engineering record.

Each team member must complete their own independent reproduction and any individual declaration required by the course. The available evidence covers automated checks and engineering runs against real services. Independent user needs and human judgments have yet to form a reportable sample set.
